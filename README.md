# meimaohouse-butler-agent

> 大庄园式管家 Agent 框架：**一个总协调管家 + 平级领域子 Agent**，人类只见管家。

## 核心架构

```
人类 👤
 │  只跟管家对话（唯一入口 / 唯一出口）
 ▼
大管家 Agent（butler-core）
 │  统筹 · 调度 · 记忆 · 汇报
 │  按需向子 Agent 分发任务，子 Agent 之间平级、互相隔离
 ▼
┌────────────┬─────────────┬──────────────┬─────────────┐
│ 厨师 Agent │ 清洁工 Agent │ 电器管理 Agent│ 外出采购 Agent│  …
└────────────┴─────────────┴──────────────┴─────────────┘
    厨房域         清洁域          电器域          采购域
```

### 三条核心设计原则

1. **见面隔离**：人类与子 Agent 永不直接交互，一切经管家转述——人类侧体验稳定，子 Agent 可随时增删替换。
2. **领域抽象 > 工具具象**：子 Agent 按"大方向/领域"划分（厨房、清洁、电器、采购…）；领域内所有具象能力（扫地、洗衣、下单买菜…）都是插件 / Skill，设备调用只是工具。
3. **上下文预算保护**：管家不背全部技能（否则上下文撑爆 → 降智），能力下沉到子 Agent，上下文隔离、按需调度。

## 目录结构

```
meimaohouse-butler-agent/
├── packages/
│   ├── butler-core/        # 大管家核心：调度器、记忆、汇报协议
│   ├── agent-sdk/          # 子 Agent 接入 SDK（接口规范）
│   └── agents/
│       ├── chef/           # 厨师 Agent（厨房域）
│       ├── cleaner/        # 清洁工 Agent（清洁域）
│       ├── appliance/      # 电器管理 Agent
│       └── shopping/       # 外出采购 Agent
├── docs/
│   └── 管家Agent-思维导图.md
└── README.md
```

## 实施路线

1. 搭框架 + 大管家骨架（调度 / 记忆 / 汇报）
2. 大管家暴露 SDK / 接口规范
3. 逐个开发子 Agent（模块化、可并行）
4. 接入真实工具与硬件（渐进增强）
